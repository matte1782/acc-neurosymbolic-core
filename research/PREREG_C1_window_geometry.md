# PREREGISTRATION — C-1: non-physical window geometry → fabricated area → false-compliant verdict

> **FROZEN BEFORE candidate generation/judging.** This document fixes the question, the candidate
> space, the external ground truth, the metrics, the objective function, the hard gates, and the
> decision rule **before** any fix is evaluated. Its purpose is to make the C-1 research
> falsifiable and bias-resistant: no goalpost-moving, no anchoring on the already-shipped fix, no
> validation against the circular control oracle. Freeze hash recorded at commit time. If this must
> change, bump to a `_v2` file and never edit a frozen row (mirrors `.idos/FRAMEWORK_BASELINE.md`).

## 0. The bias this design fights (why the obvious validation is invalid)
The repo's frozen controls (FZK 5/1, Institute 2/2, Duplex 0/21) and the 220-/110-row equivalence
oracles are **outputs of the current code** (baseline §1, ADR-006: "the frozen controls are outputs
of the current Python"). So "tests green / verdict-neutral" can only prove a fix is **faithful to
current behavior**, never that it is **correct** — and C-1 has **no conformant fixture that triggers
it**, so the existing suite is *structurally incapable* of judging a C-1 fix. We therefore evaluate
against **code-independent ground truth**: the IFC schema (the positivity contract) + the statute
(the aero rule) + a **constructed adversarial corpus** with **spec-derived expected verdicts pinned
before running any candidate**, plus oracle-free metamorphic/mutation tests.

## 1. Question (falsifiable)
What is the **optimal** way to ensure a non-physical window dimension (negative / zero / NaN / inf /
non-numeric / one-missing on `IfcWindow.OverallHeight`·`OverallWidth`, which `ifcopenshell` stores
as a raw DOUBLE and does **not** range-check despite the schema typing it `IfcPositiveLengthMeasure`)
**cannot** contribute fabricated area that lets a habitable space pass the 1/8 aero check — while
not regressing conformant files? "Optimal" is defined only by the objective function in §5.

## 2. External ground truth (code-independent oracle)
- **IFC schema (buildingSMART EXPRESS):** `IfcWindow.OverallHeight`/`OverallWidth` are
  `IfcPositiveLengthMeasure` (> 0). A value ≤ 0 / non-finite is **schema-invalid**; a valid area
  cannot be derived from it. ⇒ such a window contributes **no usable area**.
- **Statute (DM 1975 art. 5):** habitable aero = openable-window area / floor area ≥ 1/8. The
  numerator must be the area of **valid** windows only.
- **Production-safety invariant (ADR-003/004):** missing/unmeasurable ⇒ `undetermined`/violation,
  **never** a fabricated pass.

## 3. Candidate space (≥3 genuinely different; the shipped fix is ONE entry, not the default)
- **C1-A — null / pre-fix incumbent:** `if h and w: return float(h)*float(w)*scale**2`. The defect.
  Included as the differential baseline (must FAIL the safety gate).
- **C1-B — shipped per-dim guard (commit `ec07b03`):** require both dims present, numeric, finite,
  `> 0` (each dim); central `_qty` rejects non-finite/`≤0`. Evaluated impartially, not as default.
- **C1-C — model-wide schema pre-pass:** at load, scan every `IfcPositiveLengthMeasure`-typed
  quantity the checker will read; any non-positive poisons that space → `undetermined`. One
  chokepoint, broadest coverage; higher blast radius.
- **C1-D — reframe (drop the attribute path):** compute window area **only** from
  `Qto_WindowBaseQuantities.Area` (positivity-guarded); abandon `OverallHeight×OverallWidth`.
  Removes the fabrication surface entirely; **empirical risk** = more `undetermined` on real files
  (windows often lack the Qto). To be measured, not assumed.
- **C1-E — partial guard (ablation):** guard the attribute dims but NOT the `_qty` fallback. Tests
  whether the central `_qty` guard is load-bearing (expected to fail a Qto-negative pathology).

## 4. Evaluation sets
- **Adversarial corpus** (`research/corpus/adversarial/c1_*.ifc`, generated by
  `research/corpus/gen_adversarial.py` from the real fixtures; gitignored, regenerable). Each file =
  one surgical pathology with a **pre-committed expected verdict** in
  `research/corpus/expected_verdicts.json`. Minimum set: negative-dim serving window engineered to
  flip a real FZK violation→pass under C1-A; zero-dim; NaN-dim; one-dim-missing; (Qto-negative for
  the C1-E ablation).
- **Conformant control set:** the 3 real fixtures + frozen controls (neutrality gate).
- **Oracle-free tests:** `sandbox/tests/test_metamorphic.py` (injecting a non-conformant window may
  only move a verdict **toward** undetermined/violation, never toward compliant — needs no oracle)
  and `sandbox/tests/test_mutation.py` (re-inject the C-1 bug; the C-1 tests MUST fail — proves test
  power, not just presence).
- **Held-out real IFCs:** if open-repo IFC4 files with populated window Qto are obtainable, run as a
  blind generalization check; if not obtainable this round, **record the gap** (no silent skip).

## 5. Objective function (frozen) + HARD GATES
**Hard gates (disqualifying — a candidate that fails any is excluded regardless of other scores):**
- **GATE-S (safety):** 0 false-passes on the C1 corpus — no adversarial file may yield a `compliant`
  verdict (or reduce the violation count vs the spec-derived expected).
- **GATE-N (neutrality):** byte-identical verdicts on the 3 conformant fixtures + frozen controls
  (FZK 5/1, Institute 2/2 on 402/403, Duplex 0/21; `probe_controls` HELD).
- **GATE-X (no unintended crash):** no *unhandled* exception on any corpus file (an intended
  `undetermined`/None is fine; a raw `ValueError` from `float()` on garbage is a fail).

**Weighted score (0–5 each) among gate survivors — "optimal" = max weighted total:**
| Criterion | Weight |
|---|---|
| Pathology coverage / safety margin (neg, zero, NaN, inf, non-numeric, one-missing, Qto-path) | 0.30 |
| Correctness on held-out / minimal NEW false-fails on conformant data | 0.25 |
| Spec-faithfulness (IFC positivity + statute aero semantics) | 0.15 |
| Simplicity / maintainability (LOC, single chokepoint, blast radius) | 0.15 |
| Operability (distinguishes "unmeasurable" from a checker bug; diagnostics) | 0.10 |
| Performance | 0.05 |

## 6. Decision rule (frozen, applied AFTER scoring)
1. Drop all gate-failers (record why).
2. Among survivors, pick the **max weighted total**.
3. **Stability clause:** if the shipped candidate C1-B is within **0.3** of the max, keep C1-B
   (avoid churn) — but state the delta and the trade explicitly.
4. Record **all** candidate scores incl. losers and negative results (no file-drawer).
5. Output → `research/DECISION_MATRIX.md`. Implementation (if the winner ≠ shipped) is a separate,
   later step — this pilot decides, it does not silently re-implement.

## 7. Falsification criteria (what kills a candidate)
A candidate is **rejected** if it fails any hard gate; **downgraded** per refuter-confirmed weakness
(e.g. an adversarial input it misses, a conformant verdict it flips, an unhandled crash, or a
spec-misreading). The null C1-A is *expected* to fail GATE-S — if it does **not** (i.e. the corpus
fails to demonstrate the defect), the **corpus is inadequate** and must be strengthened before any
fix is judged (this is the corpus's own validity check).
