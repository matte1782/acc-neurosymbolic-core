## ADR-007: Code-audit remediation — P0 fail-closed shield + M-4 tokenized classifier (no stage flip)
Date: `2026-06-28`. Status: `ACCEPTED`. HEAD: `f9e5af4` on branch `audit/p0-m4-stabilization` (snapshot of the Stages 2–4b working tree); remediation in commits `ec07b03` (P0) + `522979d` (M-4).
A 49-agent multi-agent code audit (`research/CODE_AUDIT_REPORT.md`; 34 candidate findings → **32 adversarially confirmed, 2 refuted**) reviewed Stages 1–4(+4b). This ADR records the highest-priority remediation. **Every fix is fail-closed and verdict-neutral on the 3 fixtures** (FZK 5→1, Institute 2→2 on 402/403, Duplex 0/21 both modes; `probe_controls` HELD; 220-row + 110-row equivalence oracles 0-drift). The audit's strength is that the validated controls are the regression guard: a fix that moved a verdict would fail the oracle battery immediately.
**(P0) Three silent-false-pass holes closed (`checker.py`, `ec07b03`).** (i) **Positivity on geometry extraction (C-1/M-5):** `window_area`'s `if h and w` admitted negatives (truthy) — two negative `IfcLengthMeasure` dims fabricated a *positive* area that could false-pass a habitable room's 1/8 aero check; the bare `float()` also crashed the report on a non-numeric vendor dim. Now both dims must be present, numeric, finite, and **> 0** (each dim, so `-h*-w` cannot sneak through); `space_floor_area` requires `> 0`; `_qty` centrally rejects non-finite/`<=0` (covers height/area). A present-but-garbage quantity becomes *unmeasurable*, never a laundered value. (ii) **Fail-closed length unit (C-2):** `ifcopenshell.calculate_unit_scale` silently returns `1.0` when no `LENGTHUNIT` resolves → a millimetre model read as metres (1000× under-read passes a too-low room). New `length_scale_to_m()` requires an explicit project `LENGTHUNIT` (SI **or** conversion-based), else **RAISES**; a genuine metre model still carries `METRE` and resolves to `1.0`. (iii) **No vacuous pass on a space-less model (H-1):** findings derive only from `IfcSpace`, so `spaces_evaluated == 0` gave 0 violations / 0 undetermined → exit 0; `main()` now treats it as not-certifiable (non-zero). The two CRITICALs are **latent** — they require a *non-conformant* IFC (negative dims / missing unit); all 3 fixtures are conformant, so no control moved, but the fix removes the silent-pass *direction*.
**(M-4) Tokenized head-stem classifier (`graph.py`, `522979d`).** The substring `CONTAINS` classifier misread legal/compound names: a habitable `Soggiorno con bagno` classified **accessory** (relaxed to the 2.40 m bar AND skipped the aero check) because the string contained `bagno`, and `Messeraum` classified habitable via the internal `ess` fragment. `occupancy_via_graph` now **tokenises** the label (whitespace/punct/digit boundaries) and classifies each token by a **head-stem PREFIX match** (`STRSTARTS`) over the ontology — still graph-backed (per-token SPARQL) — then aggregates: no match → `unknown`; only accessory → `accessory`; **any habitable token, incl. a mixed accessory+habitable phrase → `habitable`** (DM-1975 Art.1: an accessory room is named by a single enumerated term; a habitable room may carry an accessory qualifier). **Design decision:** prefix, not strict whole-token equality — equality breaks agglutinative German compounds (measured **19 fixture flips**: Schlafzimmer/Technikraum/Seminarraum → unknown); and a **deterministic tokenized lookup over per-room LLM tagging** — an offline checker must not call an untrusted model at verdict time (would reintroduce the Stage-2 trust problem at runtime). Prefix keeps compounds (`Wohnzimmer`→`wohn`) while rejecting internal fragments. **Verdict-neutral: 0/110 fixture spaces reclassified.** The only behavior changes vs. substring (e.g. `Antibagno`/`Vorzimmer` → `unknown` rather than `accessory`) are in the **safe direction** — `unknown` is evaluated like habitable (stricter 2.70 m bar + aero), never granting the lenient accessory bar without confidence.
**Verified** (regression green after each commit): `test_graph` **23→35** (12 M-4 cases), `test_gate` **37/37**, `test_requirement_model` **25/25**, `test_height_keys` **9/9**, `test_geometry_fallback` **12/12**, `test_applicability_table` **18/18** (220-row 0-drift), new `test_hardening` **19/19**; `probe_controls` HELD. Adversarial edge-probes (negative/NaN/None dims, conversion-based units, empty/all-digit/mixed names) all fail-safe, no crashes. `SpaceFinding.compliant`, the law `.md`, `applicability.json`, `equiv_oracle.json` untouched.
**Honesty / scope boundary:** this ADR covers only P0 + M-4. The audit's remaining items stay open in the report backlog and are **NOT** addressed here: H-2 (pin the LLM model digest in code), M-1/M-9 (gate the `--offline`/`from_rules_json` provenance), M-2 (Ollama envelope guard), M-3 (per-space exception isolation — partially eased by the `window_area` type guard), M-6 (classified model-load error), M-8 (window-association fallback for absent `IfcRelSpaceBoundary`), and the P2 assurance items (determinism harness, reproducible artifact/env + CI, LICENSE/LGPL posture, scale/concurrency). **No stage marker flips** — this is hardening of shipped stages, not a new capability.
