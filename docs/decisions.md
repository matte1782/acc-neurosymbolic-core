## ADR-007: Code-audit remediation — P0 fail-closed shield + M-4 tokenized classifier (no stage flip)
Date: `2026-06-28`. Status: `ACCEPTED`. HEAD: `f9e5af4` on branch `audit/p0-m4-stabilization` (snapshot of the Stages 2–4b working tree); remediation in commits `ec07b03` (P0) + `522979d` (M-4).
A 49-agent multi-agent code audit (`research/CODE_AUDIT_REPORT.md`; 34 candidate findings → **32 adversarially confirmed, 2 refuted**) reviewed Stages 1–4(+4b). This ADR records the highest-priority remediation. **Every fix is fail-closed and verdict-neutral on the 3 fixtures** (FZK 5→1, Institute 2→2 on 402/403, Duplex 0/21 both modes; `probe_controls` HELD; 220-row + 110-row equivalence oracles 0-drift). The audit's strength is that the validated controls are the regression guard: a fix that moved a verdict would fail the oracle battery immediately.
**(P0) Three silent-false-pass holes closed (`checker.py`, `ec07b03`).** (i) **Positivity on geometry extraction (C-1/M-5):** `window_area`'s `if h and w` admitted negatives (truthy) — two negative `IfcLengthMeasure` dims fabricated a *positive* area that could false-pass a habitable room's 1/8 aero check; the bare `float()` also crashed the report on a non-numeric vendor dim. Now both dims must be present, numeric, finite, and **> 0** (each dim, so `-h*-w` cannot sneak through); `space_floor_area` requires `> 0`; `_qty` centrally rejects non-finite/`<=0` (covers height/area). A present-but-garbage quantity becomes *unmeasurable*, never a laundered value. (ii) **Fail-closed length unit (C-2):** `ifcopenshell.calculate_unit_scale` silently returns `1.0` when no `LENGTHUNIT` resolves → a millimetre model read as metres (1000× under-read passes a too-low room). New `length_scale_to_m()` requires an explicit project `LENGTHUNIT` (SI **or** conversion-based), else **RAISES**; a genuine metre model still carries `METRE` and resolves to `1.0`. (iii) **No vacuous pass on a space-less model (H-1):** findings derive only from `IfcSpace`, so `spaces_evaluated == 0` gave 0 violations / 0 undetermined → exit 0; `main()` now treats it as not-certifiable (non-zero).
